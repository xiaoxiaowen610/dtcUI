# Review checklist

- [ ] Change stays within its declared roadmap phase.
- [ ] Contracts and serialized formats are versioned.
- [ ] Deterministic output has no random, time, path, or environment leakage.
- [ ] Registry/import and generated-path allowlists are enforced.
- [ ] New behavior has unit or integration evidence.
- [ ] `pnpm typecheck`, `pnpm test`, `pnpm build`, and `pnpm validate:flagship` pass.
- [ ] Skipped validation is explicit and not counted as passed.
- [ ] README status and limitations remain accurate.
